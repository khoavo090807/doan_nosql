Import / Export Dữ liệu

Xuất và nhập dữ liệu sinh viên dạng JSON (MongoDB Upsert)
Export Hồ sơ Sinh viên

Xuất toàn bộ hồ sơ sinh viên (bao gồm bảng điểm) ra file JSON.

File JSON có thể dùng để backup hoặc import lại.
Import / Seeding JSON

Nạp dữ liệu từ file JSON vào MongoDB. Dùng Upsert — tự động thêm mới hoặc cập nhật.

Dữ liệu trùng MSSV sẽ bị ghi đè.
Hướng dẫn định dạng JSON
